# Slack draft listener

If the user asks to set up, install, check or fix this listener, follow `SETUP.md`
step by step. Steps marked **[YOU]** need the user (browser sign-in, sudo password,
System Settings); stop and ask them to do those, then verify before moving on.

Never commit `config.json`, `claude-settings.json`, `state/` or `drafts/`: they hold
the user's Slack ids, logs and draft contents.
